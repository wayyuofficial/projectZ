# 절차 60 — 실기 확인 요청

## 이름과 용도

**폰에서 봐 달라고 부탁할 때** 쓴다.
2026-09-10 지시 #47: *"실 기기 테스트 진행 부탁할때, 어느부분을 고쳤거나 추가했는지,
내가 뭘 봐줘야 하는지 알려줘."*

그전까지 나는 APK 만 보내고 "이상하면 말해달라" 고 했다. **그건 부탁이 아니라 떠넘기기다.**
무엇이 바뀌었는지 모르는 사람은 무엇을 볼지도 모른다.

## 읽을 것

- `git log --oneline <지난번 보낸 커밋>..HEAD -- game/ android/` — 그 사이 무엇이 바뀌었나
- 그 변경들이 근거로 쓰인 WBS 항목
- `measurements/` — 내가 이미 재서 아는 것 (사람에게 다시 재라고 하지 않는다)

## 만들 것

APK 와 **함께 보내는 확인 요청서**. 아래 다섯 칸을 **전부** 채운다. 빈 칸을 남기지 않는다.

### 1. 빌드 도장
`game/index.html` 의 sha256 앞 16자리 · 바이트 수 · 커밋.
**지난번 보낸 빌드의 도장도 같이 적는다** — 무엇과 무엇 사이의 차이인지 알아야 한다.

> 14차 감사가 `8.1` 을 실패로 둔 이유가 "어느 빌드에서 쟀는지 저장소가 모른다" 였다.
> 도장 없는 실측은 다음 감사에서 못 쓴다.

### 2. 무엇을 고쳤나
바뀐 것을 **사람이 화면에서 알아볼 수 있는 말로** 적는다. 함수 이름이 아니라 보이는 변화로.
각 항목에 **왜** 고쳤는지(어느 판정·어느 지적) 한 줄.

### 3. 무엇을 봐 달라 — **번호를 매기고, 각각 어떻게 보는지 적는다**
"이상하면 말해달라" 는 요청이 아니다. 손이 무엇을 해야 하는지 적는다.
각 항목에 **무엇이 보이면 잘못된 것인지**를 같이 적는다 — 그래야 정상과 이상을 가른다.
**판정 문구의 절을 하나씩 대응시켜 적는다. 요약하지 않는다.** 문구가 "A 하고 B 한다" 면 질문도 A·B 둘이다.
(2026-09-10: "구역이 하나 내려가고 8초 제안이 뜬다" 를 버튼 질문 하나로 줄였다가 `10.1` 이 미검증으로 남았다 — 사례 15)

### 4. 숫자로 적어 줄 것
있으면 적는다. 없으면 "없음" 이라고 적는다.
숫자를 부탁할 때는 **어느 시점의 무엇인지**를 못 박는다 (예: "구역 5 에 닿은 순간의 시각과 능력치 레벨").

### 5. 안 봐도 되는 것
**이 칸을 비우지 않는다.** 범위를 안 정하면 사람이 전부 다시 본다.
내가 이미 재서 아는 것, 이번에 안 건드린 것을 적는다.

## 절차

1. `git log --oneline <지난 빌드>..HEAD -- game/ android/` 로 변경 목록을 뽑는다
2. 각 변경을 **보이는 말**로 옮긴다. 안 보이는 변경(측정·문서·검사)은 확인 요청에 넣지 않는다
3. 위 다섯 칸을 채운다
4. APK 를 보낼 때 요청서를 **같이** 보낸다. 나중에 따로 보내지 않는다
5. 받은 답은 `measurements/device-*.json` 에 **빌드 도장과 함께** 적는다

> 검사: 다섯 칸이 다 찼는가. **3번 항목마다 "무엇이 보이면 잘못된 것인가" 가 붙어 있는가.**
> 5번이 비어 있으면 요청서가 아직 덜 된 것이다.

## 하지 않는 것

- **"이상하면 말해달라" 로 끝내지 않는다.** 그건 확인 항목이 아니다
- 안 보이는 변경(리팩터링·측정·검사·문서)을 확인 요청에 넣지 않는다 — 사람이 볼 수 없는 것은 부탁하지 않는다
- 내가 이미 잰 것을 사람에게 다시 재라고 하지 않는다
- **판정을 부탁하지 않는다.** "이거 통과인가요" 가 아니라 "무엇이 보였나" 를 묻는다.
  판정은 검증자가 한다 — 단 `10.2`("이건 게임이다")처럼 **사람만 할 수 있는 판정**은 예외다
- 한 번에 열 개를 부탁하지 않는다. 많으면 나눠 보낸다

## 이 절차가 못 막는 것 (숨기지 않는다)

**코드로 못 내린다.** "요청서가 충실한가" 는 셀 수 없다.
`위임 순서: 검사 > 스크립트 > 절차 > 인격` 에서 **절차 칸**에 남는 이유다.
빠뜨리면 사람이 "뭘 봐야 하냐" 고 되물어야 하고, 그게 이 절차가 생긴 계기였다.
