# 절차 10 — 지시 받기

## 이름과 용도
사람이 "이렇게 해줘" / "이건 틀렸다" 라고 할 때 부른다.
**바로 파일을 고치지 않는다.** 규칙 `rules/R000-지시처리.md` 를 실행하는 절차다.

## 읽을 것 (순서대로, 이것만)
1. `instructions-log.md` — 마지막 항목 번호 확인
2. `canon/` 전체 — 충돌 확인용
3. `rules/` 목록 — 충돌 확인용 (본문은 부딪히는 것만)

## 만들 것
`instructions-log.md` 맨 뒤에 항목 1개. 형식 고정:

```
## 지시 #N — YYYY-MM-DD — 한 줄 제목
### 원문
(사람이 말한 그대로. 요약으로 대체하지 않는다)
### 처리
- 층 판정:
- 충돌 확인:
- 실측 대조:
- 반영:
```

그리고 사람에게 한 줄 보고: **어느 층에 넣었는지 / 무엇과 부딪혔는지 / 무엇을 실험으로 미뤘는지.**

## 절차
1. 원문을 그대로 붙여 넣는다. → **검사**: 원문 칸이 비어 있지 않은가
2. 층을 고른다 — 정본 / 규칙 / 절차 / 검사 / 계획.
   - 이번 한 번이면 계획, 계속 지킬 것이면 규칙, 셀 수 있으면 검사까지 내린다
   - 어디에도 안 맞으면 "설계 밖"이라 말하고 되묻는다. 억지로 넣지 않는다
   - **선택지가 3개 이상인 결정이면 `rules/R001-기준먼저.md` 대로 기준을 먼저 적는다**
3. `canon/` · `rules/` 와 부딪히는지 본다.
   → 부딪히면 **어느 쪽이 이기는지 적고, 진 쪽에 폐기 표시를 남긴다.** 조용히 덮어쓰지 않는다
4. 실측과 다른 방향이면 숫자를 먼저 보여준다. 그래도 하라면 한다.
   → 표본이 작으면 규칙이 아니라 **실험**으로 등록한다
5. 반영하고 한 줄 보고. → **검사**: `python checks/run.py` 종료 코드 0
- 재시도 상한: 2회. 2회 안에 안 되면 멈추고 사람에게 묻는다

## 하지 않는 것
- 지시를 거부하지 않는다. **지시는 최종적으로 이긴다**
- 말없이 반영하지 않는다. 말없이 거부하지도 않는다
- `canon/` 을 고치지 않는다. 정본을 고쳐야 하면 사람에게 요청한다
- 원문을 다듬거나 줄이지 않는다
