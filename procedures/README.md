# 절차 (procedures)

반복 작업의 순서. 한 장에 하나만 담는다.

**다섯 칸 고정**: 이름과 용도 / 읽을 것 / 만들 것 / 절차 / 하지 않는 것

- 읽을 파일을 명시하고 **그것만** 읽는다 (원칙 8)
- 규칙을 베껴 쓰지 않는다. `rules/` 파일을 가리킨다
- 각 단계 끝에 검사를 붙이고 재시도 상한을 적는다

| 파일 | 언제 |
|---|---|
| `00-router.md` | 매번 맨 처음 |
| `10-instruction-intake.md` | 사람이 "이렇게 해줘" 할 때 |
| `20-feature-add.md` | 게임을 고칠 때 |
| `30-check-run.md` | 고친 직후 |
| `40-case-to-rule.md` | 같은 패턴 사례 2개가 쌓였을 때 |
