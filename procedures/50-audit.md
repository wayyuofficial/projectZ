# 절차 50 — 감사 회차

## 이름과 용도

검증자에게 감사를 시킬 때 **어느 범위로 시킬지** 정하는 절차다.
2026-09-09 8차 감사가 **17.0분 / 도구 53회 / 토큰 147k** 걸렸다. 매번 전수로 돌리면 감사가 병목이 된다.
그래서 회차를 두 종류로 나눈다. 무엇을 언제 쓰는지 여기서 정한다.

**나누지 않는 것 하나**: 어느 회차든 **이전 회차 판정을 물려받지 않는다.**
8차가 회귀 2건을 잡은 것은 이미 통과였던 항목을 다시 봤기 때문이다. 물려받으면 그런 건 안 걸린다.
빠른 회차는 *범위*를 줄이는 것이지 *판정을 상속*하는 것이 아니다. 범위 밖은 `통과` 가 아니라 **`이번 회차 범위 밖`** 이다.

## 읽을 것

- `plans/wbs-M1.md` — 작업과 완료 판정, 그리고 직전 회차의 판정표
- `measurements/verify/verify-*.json` — 직전 회차 (범위를 정하는 데만 쓴다. 판정을 베끼지 않는다)
- `git diff <직전 감사 커밋>..HEAD` — 무엇이 바뀌었는지
- `tools/sim_port.py` — 게임을 돌려야 하는 판정은 이걸로 돌린다

## 만들 것

`measurements/verify/verify-YYYY-MM-DD-N.json`
```
{ "검증일":"", "회차":N, "범위":"빠른|전수", "대상":"", 
  "결과":[{"항목":"1.1","판정":"통과|실패|미검증|범위밖","근거":"실행한 것과 나온 값"}],
  "요약":{"통과":n,"실패":n,"미검증":n,"범위밖":n} }
```

## 절차

### 1. 회차 종류를 고른다

| | 빠른 회차 | 전수 회차 |
|---|---|---|
| 범위 | 변경 영향권 + 직전 실패·미검증 전부 | 27개 전부 |
| 언제 | 평소. 작업 1~2건 끝날 때마다 | 실기 확인 전 · 마일스톤 마감 전 · **빠른 회차가 3번 연속 지나간 뒤** |
| 목표 시간 | 5분 안쪽 | 제한 없음 |

**변경 영향권 정하기**: `git diff` 로 바뀐 파일을 보고, 그 파일이 근거로 쓰인 작업을 전부 넣는다.
애매하면 **넣는다.** 범위를 좁혀서 놓치는 것보다 넓혀서 느린 게 낫다.

> 검사: 고른 범위에 **직전 회차의 실패·미검증이 전부 들어 있는가?** 하나라도 빠지면 범위를 다시 정한다.

### 2. 포트를 확인한다

```bash
python tools/sim_port.py
```

`어긋난 함수 N개` 가 나오면 **거기서 멈춘다.** 게임이 바뀌었는데 포트가 안 맞춰졌다는 뜻이고,
그 상태로 잰 숫자는 전부 못 쓴다. 만든 쪽에 돌려보낸다.

> 검사: 종료코드 0 · `python checks/run.py` 에서 `c16_port_sync.py` 가 `[ OK ]`.

### 3. 판정한다

- 포트로 돌릴 수 있는 것은 **`tools/sim_port.py` 를 쓴다.** 새로 옮기지 않는다.

  포트가 판정할 수 있는 것 / 없는 것:

  | 판정할 수 있다 | 어떻게 |
  |---|---|
  | 여백·백버퍼 (1.1 ①②) | `fit_game(vw, vh, dpr)` → `waste` · `backW` · `cssW` |
  | 탭 대상 크기 (7.1) | `fit_game()` 뒤 `buildButtons()` 의 `h` × `scale` |
  | 한 화면 공존 (7.2) | `buildButtons()` 의 `kind` 별 개수 |
  | 팝업이 뜨면 팝업만 (5.2) | `offlineReport` 를 넣고 `buildButtons()` |
  | 전투·구역·보상·보스 (2.x, 4.x) | `Sim.step()` · `auto_run()` |
  | 저장·오프라인 (1.3, 5.1) | `migrate()` · `applyOffline()` |
  | 예측 B4 | `auto_run(offline_every_min=30, offline_hours=8)` |

  | 판정할 수 없다 | 왜 | 대신 |
  |---|---|---|
  | 글자가 깨지지 않음 (1.1 ③) | 포트에 캔버스가 없다 | **브라우저 창으로 직접 본다** (아래) |
  | 화면이 바뀌어 보임 (3.1, 3.3, 4.2, 4.3) | 포트에 그리기가 없다 | **브라우저 창으로 직접 본다** |
  | 버튼 **글자** | 포트에 label 이 없다 (자리와 상태만 있다) | 브라우저 창 |
  | 실제 새로고침·localStorage | `data:` URL 이면 막힌다 | **로컬 서버**(`python -m http.server`)로 올리면 된다 |
  | 실기 선명도·fps | 창의 DPR 은 2, 실기는 4 | **실기 (10.1)** |
  | 게임의 실제 난수 분포 | 게임은 `Math.random()` 을 쓴다 | **실기 (8.1)** |

- **화면 판정은 브라우저 창으로 한다.** `preview_start` 로 `file:///D:/project2/game/index.html` 을 열고
  `resize_window` 로 화면 크기를 바꾼 뒤 `computer{screenshot}` 또는 `javascript_tool` 로 픽셀을 읽는다.
  창이 가려져 있으면 `requestAnimationFrame` 이 안 도니 `fitGame(); buildButtons(); draw();` 를 직접 부른다.
  끝나면 `resize_window { preset: "desktop" }` 로 되돌린다.
  **주의**: 이 창은 `data:` URL 이라 `localStorage` 가 막히고 HUD 에 "저장 실패" 가 뜬다 — 게임 결함이 아니다.
  그리고 창의 DPR 은 2, 실기는 4 다 — **창의 선명도는 실기보다 유리하다.**
  **만든 쪽이 찍어 준 그림을 근거로 쓰지 않는다. 검증자가 직접 연다.**
- 포트가 미덥지 않으면 **그 함수만** 따로 옮겨 대조하고, 어긋나면 그것을 결함으로 보고한다.
  (포트를 고치지는 않는다 — 검증자는 `tools/` 에 쓰지 않는다.)
- 그리기·사람 판단이 필요한 것은 `미검증` 이다. 추측으로 `통과` 를 주지 않는다.

> 검사: 모든 `통과` 에 **실행한 명령과 나온 값**이 붙어 있는가. 없으면 `미검증` 으로 내린다.
> 재시도 상한: 한 항목에 실행 시도 **3회**. 넘으면 `미검증(이유)` 로 두고 넘어간다.

### 4. 기준을 낮췄는지 본다

```bash
git diff <직전 감사 커밋>..HEAD -- plans/
```

판정 문구가 **약해진 방향**으로 바뀐 곳을 찾는다. 이 저장소에서 4번 적발됐다.

> 검사: `c15_prediction_lock.py` 가 `[ OK ]` 인가. 예측 문구·판정이 잠근 그대로인가.

### 5. 보고한다

**가장 불리한 사실 세 개를 먼저.** 그 다음 요약 숫자, 그 다음 항목별 한 줄.
빠른 회차면 **범위 밖으로 둔 항목을 명시**한다. 통과로 보이게 두지 않는다.

## 이 절차가 못 막는 것 (숨기지 않는다)

1. **범위를 "만든 쪽이 바꾼 파일" 로 정한다.** 만든 쪽이 손대지 않은 곳의 조용한 썩음은
   다음 전수 회차까지 아무도 안 본다. 그래서 3연속 상한을 뒀다 — 그래도 최대 3회차는 비어 있다.
2. **포트를 만든 쪽이 만들었다.** `c16` 은 "게임을 고치고 포트를 안 고침" 만 막는다.
   **처음 옮길 때의 오역은 못 막는다.** 그래서 회차마다 표본 몇 개는 원문과 나란히 읽는다.
3. **포트는 게임이 아니다.** 시드 하나의 값은 게임의 값이 아니다.
   숫자의 최종 근거는 언제나 **8.1(사람이 폰에서 플레이해 잰 기록)** 이다.

## 하지 않는 것

- **이전 회차 판정을 물려받지 않는다.** 범위 밖은 `범위밖` 이지 `통과` 가 아니다.
- **포트를 새로 짜지 않는다.** `tools/sim_port.py` 를 쓴다. 회차마다 포트가 다르면 숫자가 두 개가 되고, 둘 다 못 쓴다 (2026-09-09 8차: 두 포트가 25% 어긋났다).
- **고치지 않는다.** 결함을 찾아도 코드를 수정하지 않는다.
- 빠른 회차를 4번 연속 돌리지 않는다. 3번 뒤에는 전수다.
- 실행하지 못한 것을 실행한 것처럼 적지 않는다.
