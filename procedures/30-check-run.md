# 절차 30 — 검사 돌리기

## 이름과 용도
무엇이든 고친 직후에 부른다. 예외 없다.

## 읽을 것 (이것만)
- `checks/README.md` — 순위와 상태의 뜻

## 만들 것
- `measurements/checks-YYYY-MM-DD.json` (러너가 자동으로 쓴다)
- 실패했으면: 사례 후보 1줄을 `instructions-log.md` 에 관측으로 남긴다

## 절차
1. `python checks/run.py` 를 실행한다
2. 종료 코드를 본다
   - `0` → 통과. 3번으로
   - `1` → **차단.** 고치고 1번으로 돌아간다. 검사를 끄지 않는다
3. `SKIP` 이 있으면 이유를 읽는다. **건너뛴 검사는 통과가 아니다** (원칙 2)
4. `WARN` 이 있으면 무시해도 진행은 된다. 다만 같은 경고가 2회 나오면 사례로 남기고 1순위 승격을 검토한다
5. 검사 코드 자체를 바꿨다면 `python tools/selftest_checks.py` 로 "위반을 실제로 잡는지" 확인한다
- 재시도 상한: 3회. 3회 안에 못 통과하면 변경을 되돌리고 사람에게 보고한다

## 하지 않는 것
- 검사를 주석 처리하거나 지우지 않는다
- 기준을 통과시키려고 상한 숫자를 올리지 않는다
- `measurements/` 의 기록을 손으로 고치지 않는다 (기계가 쓴 원자료다)
- 실패를 "나중에 고치자"로 넘기지 않는다
