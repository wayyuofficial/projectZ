# 사례 — 거울에 손으로 적힌 계수(판매가 0.09)가 게임 값 변경을 삼켰다 (같은 부류 6회째)

패턴 이름: **자가고장난측정도구**
날짜: 2026-09-30
근거: instructions-log.md 지시 #131·#132 · `tools/sim_port.py` gearSellPrice · `measurements/sell-share-2026-09-18f.json`·`sell-share-2026-09-30.json`(둘 다 14.1%)
현물: 게임 판매가 계수를 0.09 → 0.10 → 0.11 로 두 번 올렸는데 판매 비중이 **두 번 다 14.1%**. 거울 파이썬에 `* 0.09` 가 글자로 박혀 있었다.

## 상황
`gearSellPrice` 는 c16 이 해시로 봉인한 함수다. 게임을 고치고 `--reseal` 을 돌리면 c16 은 초록이 된다 — **게임 본문 해시만 다시 찍기 때문**이다. 거울의 파이썬 본문이 게임과 같은지는 아무도 안 봤다(c16 의 "못 막는 것" 절 그대로).
그래서 5.1 에서 "0.10 → 14.1%" 라 적은 것은 사실 0.09 의 숫자였고, 5.3 의 "0.11" 도 안 들어갔다.

## 왜 같은 부류인가
자가 게임과 다른 값으로 돌았다. 상수를 게임에서 읽는 `num()` 틀이 있는데 이 함수만 손으로 적혀 있었다 — 사례 26(주석이 상태 칸을 삼킴)과 같은 "거울 쪽이 조용히 다르다".

## 고친 것
- 게임에 `SELL_PRICE_FRAC` 상수를 두고 거울이 `num("SELL_PRICE_FRAC")` 로 읽는다.
- 거울에 손으로 적힌 숫자가 더 있는지 훑는 검사는 **후보**(`c16` 확장: 옮긴 함수 본문의 숫자 리터럴이 파이썬 쪽에도 같은 값으로 있는지). 이번엔 grep 으로 0.09 하나만 잡았다.

## 배운 것
`--reseal` 은 "게임을 고쳤다" 를 봉인하는 것이지 "거울도 같이 고쳤다" 를 뜻하지 않는다. 리실 전에 **거울 본문을 열어 같은 자리를 고쳤는지** 보는 절차가 빠져 있었다.
