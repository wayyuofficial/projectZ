# 정본 — 게임 정체성

근거: instructions-log.md 지시 #8, #9 / plans/GAMEDESIGN.md
개정: 2026-09-08 — 지시 #8·#9로 "소형 오토배틀러"에서 교체됨. 이전 정체성은 폐기.

## 한 문장
좀비 아포칼립스 세상에서, 자동으로 싸우는 생존자를 지켜보며 무기와 능력치를 업그레이드해 더 깊은 구역까지 살아남는 게임.

## 장르
방치형 RPG (idle / incremental)

## 핵심 재미
- **성장·숫자** — 부품으로 능력치와 무기를 올리면 수치가 눈에 띄게 커진다

전략·배치는 **지시 #9로 포기했다.** 다시 넣고 싶으면 지시 로그에 새 항목으로 남긴다.

## 코어 루프 한 문장
자동으로 싸우는 생존자를 지켜보며 → 좀비를 처치해 **부품**과 경험치를 벌고 → **무기와 능력치를 업그레이드**해 강해져서 → 더 깊은 구역의 더 센 좀비를 상대한다.

## 플레이어 입력
전투 중에는 **없다.** 업그레이드 버튼 탭과 구역 이동만 있다. 이게 방치형이다.

## 목적
수익화 — 모바일 앱 광고·인앱

## 형식
단일 HTML 캔버스 (세로) → M2에서 WebView 앱으로 래핑

## 광고 삽입 지점 3개
1. 오프라인 보상 2배
2. 사망 시 부활 1회
3. 부품 획득 2배 (10분)

M1에서는 **스텁**만 만든다. 실제 SDK 연결은 M2.

## 방치형의 생명줄
- **오프라인 보상** — 자리를 비운 동안에도 부품이 쌓인다 (최대 8시간)
- **벽** — 성장 비용이 수입보다 빠르게 올라 특정 구역에서 막힌다. 막히는 게 정상이고, 그 지점이 광고 지점이다
- **저장** — 저장이 깨지면 방치형은 게임이 끝난다. `SAVE_VERSION` 은 선택이 아니다
