# 검사 (checks)

규칙 중 **셀 수 있는 것**만 코드로 내린 것. 실행: `python checks/run.py`

## 순위의 뜻
- **1순위** — 근거가 사례·실측·명시 지시. 실패하면 **막는다** (종료 코드 1)
- **2순위** — 근거가 가설. 실패해도 막지 않고 **경고만** 한다. 사례가 1건 쌓이면 1순위로 올린다

가설로 진행을 막으면 근거 없는 규칙이 코드로 굳는다. 그래서 나눴다.

## 상태
`ok` 통과 / `fail` 위반 / `warn` 2순위 위반 / `skip` 대상 파일 없음(이유 기록) / `error` 검사 자체가 터짐

`skip`은 조용히 넘어가는 게 아니다. 이유를 출력하고 JSON에 남긴다. 원칙 2.

## 원칙 5 미이행 (숨기지 않는다)
과거 산출물이 0건이라 "좋은 산출물을 떨어뜨리지 않는지" **역검증을 못 했다.**
모든 기준은 현재 **미검증**이다. M1 첫 산출물이 나오면 즉시 넣어보고 떨어지면 기준을 고친다.
