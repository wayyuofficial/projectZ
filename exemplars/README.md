# 본보기 (exemplars)

좋은 예 / 나쁜 예 한 쌍씩. 회귀 테스트로 매번 돌린다.

## 현재 상태: **비어 있다**

과거 산출물이 **0건**이라 채울 재료가 없다. 지어내지 않는다 (원칙 6 — 자기 출력을 되먹이지 않는다).

M1 첫 산출물이 나오면:
1. 사람이 "이건 좋다" 판정한 것을 `good/` 에 넣는다
2. 검사에 걸린 것 중 대표적인 것을 `bad/` 에 넣는다
3. `checks/run.py` 가 매번 이 쌍을 통과시키는지 확인하게 연결한다

**넣지 않는 것**: AI가 만든 것을 사람 검토 없이 넣지 않는다.
