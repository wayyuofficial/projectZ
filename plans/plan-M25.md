# M25 계획 — 그림을 게임 파일 밖으로

작성일: 2026-10-08
근거: instructions-log.md 지시 #190

## 사람이 정한 것
> "지금 당장은 태블릿 사용이 힘들어. 2번으로 해볼까?" — 2026-10-08 (#190, 선택지 2 = 그림·소리를 앱 안에 따로 두기)

## 무엇을 하는가
1. **그림만 뺀다.** `game/index.html` 안의 그림 data URI(webp 175개, 약 3.3MB)를 `game/img/<블록>-<해시>.webp` 파일로 쓰고, 게임은 그 경로만 든다. 그림 읽는 코드(`new Image(); im.src = …`)는 그대로 — 경로든 data URI 든 똑같이 읽는다.
2. **소리는 안에 둔다.** 소리를 파일에서 읽으려면 `fetch` 가 필요한데 c3(서버 통신 금지, 1순위)가 막는다. 그 규칙은 정본 금지목록이라 이번엔 건드리지 않는다.
3. **도구 하나로 빼기** — `tools/externalize_art.py`. 그림 만드는 도구들(build_ui·embed_zones·build_fx·build_weapons·build_hero_video·sheet_tools)은 지금처럼 data URI 를 쓰고, 그 뒤 이 도구를 돌리면 파일로 빠진다(같은 그림은 같은 이름 · 안 쓰는 파일은 지운다).
4. **검사** — c6: 게임 안에 그림 data URI 가 다시 생기면(빼기를 잊으면) 경고, 경로가 가리키는 파일이 없으면 경고. c27: 게임 파일 크기에 더해 img 폴더 합계를 적는다(상한 숫자는 그대로).
5. **앱** — 지금처럼 `file:///android_asset/index.html`. `game/` 이 통째로 앱 자산이라 `img/` 도 같이 들어간다. 저장(localStorage)의 출처가 안 바뀐다.

## 지키는 것
- 화면·동작은 그대로(그림을 읽는 자리만 바뀐다). 곡선·봉인 함수 무변경.
- 브라우저 시험은 로컬 HTTP(8124)로 — 파일을 더블클릭으로 열면 그림은 보이지만(이미지는 file:// 도 된다) 앞으로도 HTTP 로 본다.

## M25 밖
- 소리를 밖으로(c3 규칙 변경이 필요) · 그림 압축 · 상한 숫자 바꾸기.
