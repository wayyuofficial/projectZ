# M3 3단계 판정 문구 — 고칠 문구 제안 (사람이 정한다)

**사람 결정 (2026-09-14)**: *"일단 4번 그대로 두자."*
= 최대체력·체력회복을 **그대로 둔다.** 없애지도 합치지도 않고, 죽는 값도 안 건드린다.

옵션 4 에는 조건이 붙어 있었다: **"그러면 판정 문구를 바꿔야 한다."**
지금 문구는 "재설계한다" 를 전제로 쓰여 있어 재설계를 안 하면 판정할 수가 없다.

**내가 고치지 않는다.** 만든 쪽이 자기 시험을 결과에 맞춰 고치면 시험이 아니다 (R003).

## 3.1 접촉 피해

| | |
|---|---|
| 지금 | 구역 30 에서 **최대체력 0 이면 5회 이상 죽고, 권장 레벨이면 0회** — 20시드 |
| 왜 못 쓰나 | 그대로 두기로 했으므로 이 상태는 **안 온다.** 재보니 기준 사망 126회, 최대체력 잠금 시 100회 — 방향조차 반대다 |
| 제안 | **작업을 취소한다.** 3.1 은 "체력 축을 살리기 위한 피해 곡선 변경" 이었고, 살리지 않기로 했으니 할 일이 없다. WBS 에서 **취소**로 적고 이유를 남긴다 |

## 3.2 축 재설계

| | |
|---|---|
| 지금 | 다섯 축 각각이 전체 부품의 **10% 이상** (M3-B3 판정) |
| 왜 못 쓰나 | **두 가지가 겹쳐 있다.** ① 재설계를 안 하기로 했다 ② 이 지표는 **쓸모를 못 잰다** — 매수 정책이 "가장 싼 것부터" 라 다섯 축이 늘 18~19% 로 나온다 (R004). 즉 **지금도 통과한다.** 통과해도 아무 뜻이 없다 |
| 제안 | **작업을 취소하고, 사실을 기록으로 남긴다.** 완료 판정 대신 이렇게: *"최대체력·체력회복은 최적 진행에 **해롭다**(잠그면 각각 27.6%·17.0% 빨라진다, `axis-value-2026-09-14.json`). 사람 플레이에서 '죽기 싫어서' 올리는 축으로 **그대로 둔다**(2026-09-14 결정). 다시 볼 때는 `tools/axis_value.py` 로 잰다."* |

## M3-B3 예측은 어떻게 하나

문구: *"최대체력·체력회복을 **재설계하면** 다섯 축 각각이 전체 부품의 10% 이상을 가져간다"*

- **전제가 안 일어났다** — 재설계를 안 했다.
- 그런데 **결과 조건은 지금도 참이다** — 다섯 축 전부 16~20%. 글자대로 재면 **성립**이다.
- **그 성립은 거짓이다.** 지표가 쓸모를 안 재기 때문이다. 이건 M2-B3 때와 같은 구조다 — 주어와 표본이 어긋난 성립 (R004).

**제안: 반증.** 근거 문구: *"재설계를 안 하기로 했고(2026-09-14 사람 결정), 배분 지표는 매수 정책 때문에 늘 통과해 쓸모를 못 잰다(R004). 실제 쓸모는 axis_value 로 재니 두 축이 해롭다 — 최대체력 -27.6%, 체력회복 -17.0%."*

**사람이 다르게 볼 수 있다.** "예측한 일을 안 했으니 미판정" 도 말이 된다. 정하는 건 사람이다.
