# 결정 요청 — 장비 융합 시스템 · 무기 탭 → 스킬 탭 (M10, 2026-10-01, 지시 #154)

사람: "장비 시스템을 좀 갈아엎어야 할것같아. … 장비별로 각 등급별 5개의 장비가 있고, 장비는 판매하는게 아닌 스택으로 계속 쌓이는 시스템이야. 스텍으로 쌓이다가 5개 단위로 장비 융합을 하면 더 윗등급 장비로 업그레이드 할 수 있게 하는게 좋을것같아. (슬레이어 키우기) … 장비탭이 생겨나면서 무기탭이 사실상 의미가 없어졌어. 무기 탭을 없애고 다른 탭을 추가해야할 것 같은데, 난 슬레이어 키우기에 스킬 시스템을 추가했으면 좋겠는데 어떻게 생각해? 혹시 다른 아이디어 있으면 제안해줘."
→ 아래는 **제안**이다. 정하는 것은 사람이다. 정본(`canon/10-scope.md`)을 바꾸는 항목이 있다 — 승인은 사람이 `python tools/approve_canon.py` 로 한다(금지 3·4).

## 왜 바꾸나 (지금의 문제)
- 장비 = 무작위 등급 + 무작위 옵션 2줄 + 가방 + 판매. "나쁜 것 N" 일괄 판매는 **값어치(2.1^(등급−1) × 옵션 배수)** 로 견준다 → 같은 등급인데 옵션 숫자가 조금 높으면 안 팔린다(사람 질문, 2026-10-01). 옵션 종류가 달라도 숫자만 본다(공격력 +13% < 수입 +16%).
- 무기 탭은 낀 무기 1줄 + 종류 10줄(읽기만)이다. 무기는 장비 탭 뽑기에서 나오므로 **누를 것이 없다**.

## A. 장비 융합 (슬레이어 키우기식)

### A1. 장비 사다리
- **부위마다 8등급 × 5단계 = 40칸.** 등급(일반·고급·희귀·에픽·영웅·전설·초월·영원) 안에서 5 → 1 단계로 오른다(5단계가 가장 낮다).
- 뽑기는 **칸** 하나를 준다(부위·등급은 지금 확률표 그대로, 단계는 등급 안에서 무작위).
- 같은 칸 **5개 = 윗칸 1개** 융합. "일괄 융합" 버튼 하나로 모든 부위·모든 칸을 한 번에(슬레이어 그대로). 남는 수는 그대로 쌓인다(예: 13개 → 윗칸 2개 + 3개 남음).
- **판매 없음 · 가방 정리 없음 · 무작위 옵션 없음.** 칸마다 효과가 정해져 있다.

### A2. 효과 — 보유 효과 + 장착 효과
| | 보유 효과 | 장착 효과 |
|---|---|---|
| 언제 | 한 번이라도 얻은 칸은 **끼지 않아도** 계속 | 부위마다 1칸만 |
| 크기(제안) | 작다 — 칸마다 조금씩 쌓인다 | 크다 — 칸이 높을수록 |
| 무엇에 | 부위마다 고정 능력치(무기 = 공격력, 머리 = 최대체력, 몸 = 체력회복, 장갑 = 공격속도, 신발 = 수입 — 제안) | 같은 능력치 + 무기는 위력(배수) |
→ 낮은 칸도 버려지지 않는다(보유 효과). "어느 게 더 좋은가" 비교가 사라진다 — 높은 칸이 언제나 좋다.

### A3. 무기 그림 — 이미 만든 11종을 그대로
40칸 = **무기 10종 × 4칸.** 사다리를 오를수록 무기가 바뀌고 발사 효과도 따라 바뀐다.

| 칸 | 1~4 | 5~8 | 9~12 | 13~16 | 17~20 | 21~24 | 25~28 | 29~32 | 33~36 | 37~40 |
|---|---|---|---|---|---|---|---|---|---|---|
| 등급 | 일반5~2 | 일반1~고급3 | 고급2~희귀4 | … | | | | | | 영원4~1 |
| 무기 | 권총 | 쌍권총 | 소총 | 산탄총 | 화염방사기 | 석궁 | 기관총 | 유탄발사기 | 전기톱 | 레일건 |

- 순서는 지금 무기 배수 순서 그대로(권총 1.0 → … → 레일건 14.0). 지뢰는 사다리에서 빠지고(던지는 무기라 '쥐는' 그림이 어색), 쌍권총이 정식 칸이 된다 — **무기 종류 수 10 그대로**(정본 상한 안).
- 같은 무기 안 4칸은 **등급 색 테두리 빛**으로 구분(지금 있는 코드). 방어구는 부위마다 모양 3개를 사다리 구간(1~13·14~27·28~40)에 나눈다 → **새 그림 거의 없음.**
- 해금 구역(13·18·23·28)은 없어진다 — 무기는 사다리로만 바뀐다.

### A4. 같이 바뀌는 것 (사실)
- **부품 수입**: 지금 판매가 부품 수입의 약 15.5%다(`SELL_PRICE_FRAC` 주석, 지시 #139 격자). 판매가 사라지면 그만큼 비용 곡선이나 처치 보상으로 채워야 한다 — 측정 필요.
- **일일 미션**: "장비 판매 5" → "장비 융합 N" 으로 바꾼다.
- **저장**: `SAVE_VERSION` 올림. 지금 가방·낀 장비를 칸 개수로 바꿔 준다(등급 = 등급, 단계 = 옵션 값어치 순으로 배정 — 제안).
- **거울(파이썬 포트)**: `sellGear`·`gearSellPrice`·뽑기·장착이 옮겨져 있다(c16) — 같이 고치고 리실. 측정(곡선·매수 횟수) 다시.
- **정본 변경**: 랜덤 옵션 2줄 → 0, 단계 5 추가, 판매 없음, 무기 해금 구역 없음 — `canon/10-scope.md` 행 수정(사람 승인).

## B. 무기 탭 → 스킬 탭 (찬성)

### B1. 구조 (제안)
- 스킬 **8개**, 해금·레벨업. **장착 칸 4개** — 낀 스킬만 쿨타임마다 **자동 발동**(정본 "전투 중 입력 없음" 과 맞는다).
- 스킬 예시(좀비 아포칼립스에 맞춰):
| 스킬 | 효과 | 그림(나노바나나) |
|---|---|---|
| 수류탄 투척 | 범위 피해 | 수류탄·폭발(이미 있음) |
| 화염병 | 바닥에 불, 지속 피해 | 화염(이미 있음) |
| 아드레날린 | 몇 초 공격속도 ↑ | 주인공 빛 |
| 응급처치 | 체력 회복 | 녹색 십자 |
| 지원 사격(공습) | 화면 전체 피해 | 포탄 낙하 |
| 자동 포탑 | 잠깐 같이 쏜다 | 포탑 스프라이트 |
| 관통탄 | 다음 N발 관통 | 탄 꼬리 |
| 집중 사격 | 지금의 '탭!' 버프(×1.12, 3초, 45초) | 이미 있음 |
- 스킬 재화(정할 것): ① **스킬북**(보스·일일 미션에서 — 새 재화) ② 설계도 같이 씀 ③ 부품.

### B2. 다른 탭 후보
| 아이디어 | 내용 | 좋은 점 | 비용 |
|---|---|---|---|
| **환생(프레스티지)** | 구역 30 도달 뒤 처음부터, 대신 영구 배수 | 방치형 장기 플레이의 핵심 — 지금은 30구역(약 3시간)이면 끝난다 | 중(저장·곡선) |
| 동료(드론·군견) | 옆에서 같이 싸우는 보조, 레벨업 | 화면이 풍성 | 중(그림·전투 함수) |
| 생존자 캠프 | 구출한 생존자로 시설(작업장·의무실) → 방치 생산 | 세계관·오프라인 보상과 맞는다 | 큼 |
| 유물 | 보스 드랍 영구 패시브 | 보스 잡는 이유 | 작음 |

**권고: 스킬 탭(무기 탭 자리) + 환생(다음 단계).** 둘 다 서버 없이 된다(금지 5).

## 사람이 정할 것
1. 장비 사다리 — **8등급 × 5단계 = 40칸**으로 갈지(다른 수면 적어 주세요).
2. 효과 — **보유 효과 + 장착 효과** 둘로 나눌지 / 장착 효과만.
3. 무작위 옵션 2줄 — **완전히 없앨지** / 높은 등급에만 남길지.
4. 무기 사다리 — 위 표(10종 × 4칸, 지뢰 빼고 쌍권총 넣기)대로 갈지.
5. 지금 저장의 장비 — 칸으로 바꿔 줄지(권고) / 초기화.
6. 스킬 — 8개·장착 4칸·자동 발동으로 갈지, 예시 중 빼거나 넣을 것.
7. 스킬 재화 — 스킬북(새 재화) / 설계도 / 부품.
8. 집중 사격('탭!') — 스킬 하나로 옮길지 / 지금처럼 따로.
9. 환생 — 이번에 같이 / 다음에.
10. 순서 — 권고: ① 장비 융합 → ② 스킬 탭 → ③ 환생. 각 단계 끝에 에뮬레이터로 본다.
