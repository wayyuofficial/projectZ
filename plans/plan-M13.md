# M13 계획 — 앞으로 나아가는 전투

작성일: 2026-10-02
근거: instructions-log.md 지시 #161

## 사람이 정한 것 (지시 #161)
> 캐릭터가 좀비를 처치하며 앞으로 나아가고 뒤 배경이 걸음에 맞춰 스크롤. 다음 구역은 오른쪽 화면 끝으로 나가면서. → 배경 "지금 그림 + 시차", 걷기 "Veo 영상 → 프레임".

## 무엇을 만드는가
- **걷기 ↔ 사격**: 화면에 좀비가 없거나 아직 멀면(사격 거리 밖) 주인공이 **걷는다** — 바닥(빠르게)·뒤 배경(느리게, 시차) 이 왼쪽으로 흐른다. 좀비가 오면 멈춰 겨누고 쏜다.
  - **전투 계산은 그대로**(좀비 걸음·사격 판정·피해). 그림만 바뀐다 — 곡선·밸런스가 흔들리지 않는다. 걷는 동안 좀비도 같은 속도로 왼쪽으로 더 밀려 보이게(상대 속도) 한다.
- **배경 스크롤**: 바닥 타일은 이음매가 없다 — 그대로 흐른다. 뒤 배경(구역 그림 512)은 **좌우로 뒤집어 이어 붙여** 끝없이 흐른다(이음매가 대칭으로 이어진다). 속도: 바닥 1 · 뒤 배경 0.35.
- **구역 이동 연출**: 구역의 마지막 좀비를 잡으면 → 주인공이 **오른쪽 끝으로 달려 나간다**(0.9초) → 화면이 어두워졌다 밝아지며 다음 구역 그림 → 왼쪽에서 **걸어 들어온다**(0.9초) → 전투. 이동 중에는 좀비가 안 나온다.
  - 이 시간(약 2초)은 **진짜 시간**이다 — 거울(`tools/sim_port.py`)도 같은 시간만큼 좀비를 안 내보낸다(60구역 × 2초 ≈ 2분). 죽어서 물러날 때는 지금처럼 바로.
- **걷기 동작**: Veo(veo-3.1-fast)로 제자리 걷기 영상 → 12fps 프레임(지금 사격 동작과 같은 길, `art/hero/build_hero_video.py`). 걷는 동안 총은 내려(그리지 않는다).

## M13 밖
- 배경을 이음매 없는 가로 그림으로 다시 그리기(사람이 '지금 그림 + 시차' 를 골랐다).

## 지키는 것
- 전투 함수(stepCombat 등, c16)는 구역 이동 대기(`travel`) 한 줄만 — 거울 같이 고치고 리실.
- 파일 크기 상한 5MB(c27) — 걷기 프레임 약 +100K.
