# 결정 요청 — 구역 31~60 새 지역 6묶음 (M11 2부, 2026-10-01, 지시 #156)

사람: "솔직히 아직 스테이지가 부족한 느낌이긴 해." → 60구역 · 새 지역 컨셉은 AI 제안 → 사람 확인.
→ 아래는 **제안**이다. 사람이 확인하기 전에는 그림을 만들지 않는다(나노바나나 비용).

## 이야기 흐름
지금 30구역: 도시 → 지하철 → 공장(항만 부두 포함) → 숲·늪 → 군 기지(야전 병원 포함) → 연구소 **근원 격납실**에서 끝난다.
31~60 은 **"근원을 막지 못했다 — 감염이 세계로 퍼진 뒤, 마지막 둥지를 찾아가는 길"**. 기존 묶음과 겹치는 장소(항구·병원)는 피했다.

## 만드는 양 (M9 와 같은 길)
- 배경 6장 · 좀비 16종(위 표) · 보스 6종 — 나노바나나 flash 512px, 좀비 걷기 4·공격 2, 보스 걷기 2·돌진 준비·돌진.
- 첫 장은 주인공·기존 좀비를 참조로 그려 화풍을 잇는다.

## 같이 정할 것 — 파일 크기
- 지금 게임 파일 **2.65MB / 상한 3.2MB**(검사 c27, 예측 M9-P1 — 단일 HTML 로딩 시간 때문).
- 묶음 하나에 배경 ~140K · 좀비 ~105K · 보스 ~47K ≈ **290K** → 6묶음이면 **약 +1.75MB = 4.4MB** → 상한을 넘는다.
- 선택지:
  1. **상한을 5MB 로 올린다** — 그림 품질 그대로. 폰 첫 로딩이 조금 길어진다(지금 기준 약 1.7배).
  2. **배경을 낮은 품질로**(지금 것도 같이 다시 압축) — 약 3.6MB, 상한 4MB. 배경이 조금 흐려진다.
  3. **지금 보는 묶음만 풀기**(이미 좀비는 그렇게 한다) + 1번 — 메모리는 그대로, 파일 크기만 늘어난다.
- 권고: **1 + 3**(품질 유지, 로딩은 에뮬레이터로 확인).

## 같이 바뀌는 것 (사실)
- 정본 '구역' 30 → 60, '목표 체류 곡선'은 31~60 을 새로 잡는다(0.6×1.12^(z−1) 을 그대로 이으면 구역 60 하나가 449분). 제안: 31 부터 ×1.04 씩 → 60구역 총 약 6시간. 사람 승인.
- 장비 끝칸·능력치로 60 까지 가는지 측정 — 모자라면 무기 성장·좀비 성장을 맞춘다.

## 사람이 정할 것
1. 6묶음 — 위 표대로 / 바꿀 묶음(다른 후보에서 또는 직접).
2. 좀비·보스 — 위 표대로 / 고칠 것.
3. 파일 크기 — 1+3(권고) / 2 / 다른 것.
