# M17 계획 — 진짜 광고(보상형)

작성일: 2026-10-08
근거: instructions-log.md 지시 #172 / 정본 `canon/00-identity.md` "광고 삽입 지점 3개 — 실제 SDK 연결" / `plans/분석-개선점-2026-10-05.md` B1("광고가 진짜가 아니다")

## 사람이 정한 것
> "광고보기 버튼을 누르면 광고없이 바로 작동이 되는데, 광고를 붙이고싶어." — 2026-10-08 (#172)

## 무엇을 하는가
1. **광고는 안드로이드 껍데기에서만** — Google AdMob **보상형 광고**(끝까지 보면 보상). 게임 HTML 에는 통신을 넣지 않는다(정본 금지 5·검사 c3 그대로). 게임은 `window.AdBridge` 가 있으면 껍데기에 "광고 띄워줘" 를 부탁하고, 껍데기가 다 본 뒤 `window.onAdResult(종류, 성공)` 으로 알려준다.
2. **광고 자리 3곳 그대로** — 오프라인 보상 2배 · 쓰러졌을 때 복귀 · 부품 2배 10분. 보상 내용은 바꾸지 않는다(`adGrant` 로 이름만 옮김).
3. **브라우저에서는 지금처럼** — 다리(`AdBridge`)가 없으면 누르자마자 보상(개발·저사양 태블릿 시험용).
4. **광고가 아직 없을 때**(불러오는 중·오프라인) — 보상을 주지 않고 "광고 준비 중" 을 띄운다. 비행기 모드로 공짜 보상을 받는 길을 막는다.
5. **시험 광고 ID** — Google 이 공개한 시험용 앱 ID·보상형 단위 ID 로 붙인다. 진짜 ID 는 사람이 AdMob 계정을 만든 뒤 `android/app/src/main/res/values/ads.xml` 두 줄만 바꾼다(계정 가입은 사람 — 정본 금지 2).

## M17 밖 (안 한다)
- AdMob 계정 가입·앱 등록·스토어 등록(사람) · 동의 팝업(UMP — 유럽 사용자 대상, 출시 전에 따로) · 전면·배너 광고 · 인앱 결제.

## 지키는 것
- 검사 c3(게임 HTML 통신 0) · c16 거울(전투 함수 무변경 — `adReward` 는 거울 밖) · 저장 판본 그대로 · 탭 크기.
