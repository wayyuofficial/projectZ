# 26차가 찾은 장부 빈칸 — 메울 안 (사람이 정한다)

새 판정 문구 5개는 26차에서 **전부 통과**했다. 동작에는 문제가 없다.
문제는 문구를 다듬다가 **아무도 안 세는 자리**가 셋 생겼다는 것이다.
아래는 **제안**이다. 그대로 쓰든, 고치든, M3 으로 미루든 사람이 정한다.

---

## 빈칸 1 — 체류를 재는 판정이 M2 에 하나도 없다

| | |
|---|---|
| 사실 | 정본의 목표는 **체류**(z) = 4분 × 1.05^z 다. 그런데 2.2 는 주어가 **누적 도달**로 바뀌었고, 4.3 은 체류를 M3 으로 명시해 뺐고, 3.1 은 벽 비 선을 없앴다 |
| 숫자 | 같은 빌드·같은 20시드에서 **도달 밖 2개(통과) / 체류 밖 13개** |
| 왜 생겼나 | 톱니(무기 구매 순간의 급가속) 때문에 구역별 체류가 들쭉날쭉해 도달로 옮겼다. 옮긴 것 자체는 사람이 (c) 로 정한 일이다. 다만 **옮기면서 원래 목표를 세는 자리를 안 남겼다** |

**안 (a) — M3 항목으로 명시해 넘긴다 (권함)**
`plans/plan-M3.md` 에 한 줄을 만든다: *"체류 곡선 — 현재 밖 13개. 무기 배수·업그레이드 곡선을 다시 짜서 줄인다."*
M2 는 도달로 닫고, **넘긴 자리에 이름을 붙인다.** 지금은 넘긴 자리가 비어 있는 게 문제지 넘긴 것 자체가 문제는 아니다.

**안 (b) — M2 에 정보 항목으로 남긴다**
2.2 에 절을 하나 더한다: *"체류 밖 개수를 기록에 남긴다(선 없음, `c18` 이 정보로 출력)."*
세지만 떨어뜨리지는 않는다. 지금 상태를 장부에 보이게만 한다.

**안 (c) — M2 에서 체류로 다시 판정한다**
지금 13개라 **즉시 실패**다. 무기 배수 재설계가 따라와야 하고 마감이 늦어진다.

## 빈칸 2 — `M2-B4` 반증의 후속을 맡은 작업이 없다

| | |
|---|---|
| 사실 | B4 반증 조건은 "범위 밖이면 **부스트 배수나 지속 시간을 다시 정한다**". 반증은 섰는데(5/6, 구역 20 = 0.499) 배수·지속은 그대로고, 비를 세던 5.1 은 새 문구에서 빠졌다 |
| 왜 생겼나 | "만든 것" 과 "예측" 을 한 문구에 섞지 말자고 5.1 에서 분리했다. 분리는 옳았는데 **받는 쪽을 안 만들었다** |

**안 (a) — 반증을 받되 손대지 않는다고 적는다 (권함)**
0.499 는 선에서 0.001 밖이고 잡음 폭 안이다. WBS 에 한 줄: *"B4 반증 접수 — 부스트 배수·지속은 그대로 둔다. 사유: 6구역 중 5구역이 안에 들고 벗어난 1구역이 0.001 차. 다시 정할 만한 크기가 아니다."*
**반증을 받고도 안 고치는 것은 괜찮다. 받지도 않는 것이 문제다.**

**안 (b) — 부스트 지속을 실제로 다시 정한다**
구역 20 을 0.5 위로 올린다. 밸런스 재측정과 재판정이 따라온다.

## 빈칸 3 — 4.3 둘째 절이 2.2 와 같은 값이라 혼자 못 떨어진다

| | |
|---|---|
| 사실 | 4.3 둘째 절 "도달 밖 4개 미만" 은 2.2 와 **완전히 같은 수치**다. 2.2 가 통과하는 한 4.3 둘째 절은 구조적으로 통과한다 (R004) |
| 빠진 것 | B3 원문의 주어는 **"무기 전/후 비교"** 였다. 새 문구가 그 비교를 버렸다 |
| 검증자 실측 | `--no-new-weapons` 로 재면 **밖 5개**, 무기 있으면 **밖 2개** — 무기가 실제로 곡선을 살리고 있다 |

**안 (a) — 비교를 되살린다 (권함)**
4.3 둘째 절을 이렇게 바꾼다: *"새 무기를 뺀 곡선(`--no-new-weapons`)보다 도달 밖 개수가 **줄어든다**. 안 줄면 무기 배수를 다시 정한다."*
지금 5 → 2 로 줄어 통과하고, 무기 배수를 잘못 건드리면 **실제로 떨어진다.** 2.2 와 독립이다.

**안 (b) — 둘째 절을 뺀다**
4.3 을 그림 판정(픽셀 동일 0)만으로 둔다. 곡선은 2.2 가 혼자 맡는다. 겹침은 사라지지만 무기와 곡선의 연결은 아무도 안 본다.

## 딸린 것 둘 (판정 문구가 아니라 사실 오기)

|---|---|---|
