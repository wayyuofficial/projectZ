## 무엇을 하는가
1. 배경음악 OGG(약 0.35MB, base64 로 0.46MB)를 `game/snd/bgm-<해시>.ogg` 로 빼고 게임은 경로만 든다.
2. 재생을 웹오디오 버퍼(atob → decodeAudioData) → **오디오 요소**(`new Audio(경로)`, loop)로. 파일을 fetch 하지 않으므로 c3(서버 통신 금지)는 그대로다.
3. 요소를 웹오디오에 잇지 않는다 — 앱은 file:// 에서 열리는데 그때 요소를 웹오디오에 이으면 출처가 달라 소리가 0 으로 나온다. 그래서 볼륨은 요소 볼륨(최대 0.75)으로만, 끝 리미터(sndBus)는 효과음만 거친다.
4. 광고를 볼 때·앱이 내려갈 때 같이 멈추고, 돌아오면 이어서 튼다(`bgmHold`).
5. `tools/build_sound.py` 가 배경음악을 파일로 쓰고 옛 파일을 지운다. c6 이 `snd/` 경로도 본다.

## 지키는 것
- 효과음은 그대로(게임 안). 저장 출처 그대로(file:///android_asset). 설정의 배경음 켜기·슬라이더 그대로.

## M26 밖
- 효과음 밖으로(c3 규칙 변경 필요) · 상한 숫자.
