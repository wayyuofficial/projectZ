# 에뮬레이터 점검 — M17 광고 (2026-10-08)

빌드: `game/index.html`(M17) + 광고 다리 껍데기. 안드로이드 스튜디오에서 ▶ Run 'app'.
**에뮬레이터가 'Google Play' 이미지여야 한다**(Pixel 6 기본 이미지는 대개 Play 포함 — Device Manager 에서 Play 아이콘 확인). 인터넷 연결 필요.
항목마다 "됨" 또는 "뭐가 달랐는지" 한 줄. 예측 M17-P3 의 판정 근거입니다(판정은 `tools/judge_prediction.py`).

## 볼 것

| # | 무엇을 | 보여야 하는 것 | 답 |
|---|---|---|---|
| 1 | 앱을 켜고 10초 기다린 뒤 아래 **'광고 · 부품 2배'** 를 누른다 | 'Test Ad' 표시가 있는 광고 화면이 뜬다(동영상 또는 그림) | |
| 2 | 1번 광고를 **중간에 닫는다**(X 가 나오면 바로, 보상 확인 창이 나오면 '닫기') | 보상 없음 — 버튼 그대로, '끝까지 보면 보상' 글자 | |
| 3 | 몇 초 뒤 '부품 2배' 를 다시 눌러 광고를 **끝까지** 보고 닫는다 | 버튼이 '2배 9:59' 처럼 바뀐다(보상 들어옴) | |
| 4 | 쓰러질 때 뜨는 **'광고 보고 구역 N 복귀'** | 광고가 뜨고, 끝까지 보면 그 구역으로 돌아간다(8초 제안이 광고 중 끝나도) | |
| 5 | 앱을 끄고 한참 뒤 켜서 **오프라인 보상 '광고 보고 2배 받기'** | 광고 뒤 부품이 2배로 들어온다 | |
| 6 | 에뮬레이터 인터넷을 끄고(설정 → 네트워크 → 비행기 모드) 앱을 새로 켠 뒤 광고 버튼 | 광고가 안 뜨고 '광고 준비 중' — 보상 없음, 게임은 그대로 돈다 | |
| 7 | 광고를 본 뒤 소리 | 광고가 닫히면 게임 소리가 다시 난다(광고와 겹치지 않는다) | |

## 이번에 안 넣은 것
AdMob 계정·진짜 광고 ID(사람이 가입 — 아래) · 유럽 동의 팝업(UMP) · 전면·배너 광고.

## AdMob 계정 (사람이 할 일 — 출시 전)
1. admob.google.com 에서 가입 → 앱 추가(Android, 아직 스토어 없음 선택) → '보상형' 광고 단위 만들기.
2. 받은 **앱 ID**(`ca-app-pub-…~…`)와 **광고 단위 ID**(`ca-app-pub-…/…`)를 AI 에게 알려주면 `android/app/src/main/res/values/ads.xml` 두 줄을 바꾼다.
3. 진짜 ID 로 시험할 땐 AdMob → 설정 → 테스트 기기에 등록한다(자기 광고를 보면 계정 정지 위험).
