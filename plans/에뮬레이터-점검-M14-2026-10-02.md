# 에뮬레이터 점검 목록 (M14 4.1, 2026-10-02)

사람이 에뮬레이터(또는 폰)에서 본다. 볼 것마다 '좋다 / 고칠 것' 만 적어 주면 된다.

## 미리 잰 숫자 (클라우드 Playwright — GPU 없는 소프트웨어 그리기)
| 조건 | 첫 로딩 | 프레임(중앙 · 95%) |
|---|---|---|
| CPU 그대로 · 화면 배율 1 | 0.4초 | 16.7ms · 16.8ms (60fps) |
| CPU 그대로 · 배율 2.625(중급 폰) | 0.4초 | 33ms · 50ms |
| CPU 4배 느리게 · 배율 1 | 1.5초 | 33ms · 50ms |
| CPU 4배 느리게 · 배율 2.625 | 2.4초 | 167ms · 217ms |
- **장면과 상관없다** — 평소 전투·좀비 8마리 + 스킬 4개·달리기 스크롤이 같은 값이다. 화면 픽셀 수(배율)와 CPU 에만 달린다 → 화면 전체를 매 프레임 다시 그리는 비용. 폰은 GPU 로 그려 이보다 빠를 것이지만, **실기에서 느리면 배경을 매 프레임 그리지 않고 굳혀 두는 최적화**(`anthropic-skills:canvas-game-optimize`)가 다음 일이다.
