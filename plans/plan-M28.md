## 무엇을 하는가
1. **자재(G.mats)** — 보스를 잡을 때마다 2 × 회차, 처음 깬 구역마다 3. 무전실 레벨만큼 더(+10%/Lv, 내림).
2. **시설 6개** (표 `CAMP_BUILDS` — 값은 사람이 바꿀 수 있다). 모두 최대 10레벨, 값 = 5 × 1.45^레벨(자재), 시간 = 5분 × 1.55^레벨.

| id | 이름 | 효과(레벨당) |
|---|---|---|
| clinic | 의무실 | 체력회복 +10% |
| armory | 무기고 | 치명타 피해 ×(1 + 4%) |
| range | 사격장 | 치명타 확률 ×(1 + 3%) (상한 60% 그대로) |
| workshop | 작업장 | 스킬 피해 +5% |
| power | 발전소 | 오프라인 보상 비율 +5%p (0.5 → 최대 1.0) |
| radio | 무전실 | 자재 획득 +10% |

3. **짓기** — 한 번에 하나. 누르면 자재를 내고 끝나는 시각(실제 시계)을 적는다. 꺼 둬도 시간이 간다(다시 켜면 완공). 광고를 보면 남은 시간 30분 당김.
4. **환생해도 남는다** — 자재·시설 레벨·짓는 중인 것 모두.
5. **화면** — 전투 화면 오른쪽 아래 작은 버튼(스피커 왼쪽, 천막 아이콘). 누르면 녹슨 팝업: 자재 · 짓는 중(남은 시간) · 광고 버튼 · 시설 6줄(효과 지금 ▸ 다음 · 값/짓기 버튼). 다 지으면 알림 줄 + 버튼에 점.
6. **거울** — killZombie(자재) · skillHit · medalMult(능력치 3) · applyOffline · freshState · migrate · buildButtons(작은 버튼·팝업) · campTick(시계)·campBuild 같이 고치고 리실. 기본 곡선은 짓지 않는다(퀘스트처럼) — `auto_run(camp=True)` 측정 옵션.

## 지키는 것
- 첫 회차 기본 곡선 327.3분(짓지 않는 시뮬). 정본 '캠프' 행은 AI 타이핑 — 사람 승인 전엔 c0 이 막는다.
- 하던 저장본: 자재 0 · 시설 0 으로 시작.
