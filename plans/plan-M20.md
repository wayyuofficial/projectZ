## 사람이 정한 것
> "게임에 설정 팝업을 넣어서 배경음과 효과음을 조절 할 수 있는 옵션을 만들어줘." — 2026-10-08 (#183)

## 무엇을 하는가
1. **스피커 버튼 → 설정 팝업** — 전투 화면 오른쪽 아래 스피커 버튼(M16)을 누르면 끄고 켜는 대신 '설정' 팝업이 뜬다. 아이콘은 둘 다 꺼졌을 때만 '꺼짐' 모양.
2. **배경음 · 효과음 줄 둘** — 줄마다 [−] [+] 로 크기 0~10단계(한 단계 10%), [켜짐/꺼짐] 버튼. 크기는 막대와 숫자로 보인다. 누르면 바로 들린다(효과음은 '띵' 한 번).
3. **따로 저장** — 게임 저장 칸이 아니라 따로(`zombie-idle-sound2`, 저장 판본 그대로). 옛 켜짐/꺼짐(`zombie-idle-sound` = off)은 둘 다 꺼짐으로 옮긴다.
4. **거울** — 버튼은 봉인 함수 `buildButtons` 안이라 거울(`tools/sim_port.py`)의 같은 자리에 팝업 버튼을 넣고 리실(c16). 버튼 크기는 탭 선(tap_check) 위.

- 진동 · 언어 · 저장 내보내기/지우기 옮기기(분석 B3 — 따로 정한다).
